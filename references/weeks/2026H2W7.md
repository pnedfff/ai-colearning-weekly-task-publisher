# 2026H2W7｜从分镜到短视频：讲清一个真实工作场景

## 群公告

本周不做“高端广告片”作业，也不要求用某个指定平台。请从你真实、脱敏的工作或学习场景里选一件小事，把它先讲成 **4 格分镜**，再生成一条 **5 至 15 秒** 的短视频样片并复盘一次。

重点不是把视频做得多华丽，而是练会一条可复用链路：**选题收窄 → 分镜拆解 → 生成样片 → 人工校对 → 修改提示词**。

可以用 Codex、WorkBuddy、ZCode、Deep Code 等同类工具协助策划和整理提示词；图像、视频工具使用你已经有权使用的即可。不为交作业购买会员、充值、上传隐私素材或绕过平台限制，也不要求公开发布视频。

## 任务目标

把一个别人看不懂的工作场景，压缩成一条边界清楚、可验证、可继续改进的小短片。

本周完成后，你应能：

- 用 4 个连续镜头讲清“问题 / 动作 / 结果”。
- 把分镜转换成图像关键帧和视频生成提示词。
- 只生成一个样片，指出至少一个问题并人工改正。
- 明确素材授权、隐私、付费和发布边界。

## 参与者流程

1. 选一个小而真实的场景
   - 可选：展示一个产品或功能、说明一个工作流程、呈现一次整理前后对比、讲清一个学习成果。
   - 不要选真实客户案例、未公开产品资料、人物肖像、聊天记录、订单、财务数据或无法确认授权的网络素材。
   - 用一句话写清：给谁看、想让对方记住什么、视频不超过 15 秒。

2. 先写 4 格分镜，不要急着生成
   - 每格写清：时间、画面主体、动作或镜头、要传达的信息、转场方式。
   - 推荐节奏：0–3 秒提出场景，3–6 秒展示关键动作，6–9 秒看到变化，9–15 秒给出结果或下一步。
   - 不依赖模型在画面里生成中文文字；字幕、标题和口播可单独写在分镜里，后续再人工添加。

3. 生成一张关键帧或分镜展示图
   - 先只做一个镜头的关键帧，核对主体、构图、光线和隐私边界。
   - 如使用自己的产品图、截图或照片，确认你有使用权，并先移除客户、账号、订单、聊天窗口等信息。

4. 只生成一条视频样片
   - 以关键帧或文字分镜生成一条 5 至 15 秒样片；工具长度受限时，生成其中一个镜头的短样片即可。
   - 第一次只跑一条，不批量生成，不直接发布，不为补次数购买额度。
   - 如果工具在生成前要求付费、上传、公开分享或使用不清楚的素材，先停下确认。

5. 人工验收并做一次修正
   - 对照分镜检查：镜头顺序是否连贯、主体是否跑偏、是否出现错误文字、是否有不该出现的人或信息。
   - 至少改一项：提示词、镜头动作、画面主体、时长、转场或禁止项。
   - 若不再生成第二条样片，也要写出修改后的提示词和原因。

6. 整理打卡材料
   - PR 只提交脱敏报告、分镜表、提示词和复盘；不要把含隐私、版权不清、体积过大的原始图片或视频上传到公共仓库。
   - 无法生成视频时，提交“4 格分镜 + 关键帧或文字画面稿 + 视频提示词 + 环境 / 额度阻塞说明”，作为基础完成。

## 可复制提示词

先把想法压缩成 4 格分镜：

```text
我要把一个真实但已脱敏的工作场景做成一条 5 至 15 秒 AI 短视频。

场景：［我想展示的工作场景］
观众：［谁会看］
一句话信息：［希望对方记住什么］
已有素材及授权情况：［自制 / 已获授权 / 无需外部素材］
禁止出现：真实人物、客户信息、账号、订单、未授权品牌、乱码中文文字。

先不要生成图片或视频。请只输出一张 4 格分镜表，每格包含：
1. 时间范围；
2. 画面主体和动作；
3. 镜头或构图；
4. 要传达的信息；
5. 转场方式；
6. 隐私、授权或跑偏风险。

让 4 格形成连续故事，不要写成泛泛的广告词。
```

生成单个关键帧：

```text
根据下面第［1 / 2 / 3 / 4］格分镜，只生成一张关键帧画面。

［粘贴这一格分镜］

要求：主体明确、构图简洁、画面中不出现任何文字、logo、人物肖像或敏感信息；不要模仿具体品牌或广告团队的风格。先说明画面可能跑偏的两点，再生成关键帧。
```

生成视频样片前的安全检查：

```text
我要用这张关键帧 / 这段分镜生成一条短视频样片，时长目标为［5 至 15］秒。

请先不要生成，检查：
1. 是否含有未授权素材、真实人物、客户信息、账号或订单；
2. 是否会要求付费、上传、公开分享或使用来源不明的插件；
3. 第一条样片的验收标准是什么；
4. 出现哪些情况必须立即停止；
5. 生成后我应优先人工检查什么。

确认后，再把视频提示词压缩成一段可直接复制的文字：只描述一个连续镜头主线，不要让模型生成字幕或画面文字。
```

## 完成标准

- 有一个真实、脱敏、授权清楚的小场景，而不是套用产品广告模板。
- 完成 4 格连续分镜，每格都有时间、画面 / 动作、镜头或构图、信息和转场。
- 至少生成一张关键帧，并生成一条 5 至 15 秒视频样片；如工具受限，提交完整基础完成路径和阻塞说明。
- 对第一条样片做人工验收，并记录至少一次修改或停止决定。
- 说明素材授权、付费、上传和公开发布边界；不上传隐私或版权不清素材。

## 带班复盘

- 下一周要延续的规则：先用一条样片验证，再决定是否继续生成或发布。
