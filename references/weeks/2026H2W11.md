# 2026H2W11｜四类资料合成一份可信的客户档案

日期：2026-09-14 至 2026-09-20。

## 群公告

本周用聊天记录、邮件、合同草案和客户表，做准一份客户全景档案。重点是结论有来源、冲突能识别、未知不编造。下周再将跑通的方法封装成 Skill，换客户验证复用。

新同学先安装 [周任务发布器](https://github.com/pnedfff/ai-colearning-weekly-task-publisher)；老同学更新后领取任务。使用 Codex、WorkBuddy 或 DSH，需具备本地文件读取能力。本周没有额外专用 Skill 安装要求，也不需要得到大脑会员。

## 任务目标

把四类资料中的事实、需求、待确认事项与建议分清楚，为下一步跟进提供依据。不要为追求“完整”补造金额、签约状态、培训时间或服务承诺。

## 材料与参与者流程

1. 下载本仓库（GitHub Code → Download ZIP，或让 Agent 克隆）；取 [客户 A 材料](../materials/2026H2W11/客户A/) 的四个文件放入独立练习目录 input。材料均为原创虚构，原件只读。
2. 让 AI 盘点输入，说明整理结构与需要核对的问题，再生成初稿到 output。
3. 交付：客户全景档案.md、冲突与待确认.md、核验记录.md。档案包括概况、时间线、需求、关键事实、状态与下一步建议。
4. 金额、日期、承诺与阶段逐项写来源（文件名及具体条款/记录）。事实与建议分栏；冲突不能由 AI 自动选定胜者。
5. 本人抽查至少 3 条关键结论，包括至少一项冲突；在核验记录中写原结论、来源、判断与修改。如没有发现错误，也要记录通过依据。
6. 初稿完成后再打开 [人工验收参考](../materials/2026H2W11/验收参考.md)，检查遗漏并修订。客户 B 留给下周新会话复用验证。
7. 有自己的资料可选做脱敏案例，但公共 PR 只提交过程报告；不上传真实客户材料。

## 可复制提示词

```text
请帮我完成 2026H2W11 作业。我已将虚构客户 A 的四类材料放入 input。
先盘点四个文件，告诉我档案结构、来源标注方式及需核对的问题，再按这些要求完成：
1. input 原件只读，所有成果写入 output。
2. 输出客户全景档案.md、冲突与待确认.md、核验记录.md。
3. 金额、日期、账号数、签约状态和承诺必须标注文件名与具体条款/记录。
4. 信息缺失写“原文未说明”；信息冲突并列原值与来源，写“待人工确认”。
5. 下一步建议和已确认事实分开，不替任何一方承诺日期、价格或服务。
6. 核验记录先留待我实际检查，不能冒充我已人工验收。
本轮只读取客户 A，不读取客户 B 和人工验收参考，不需要联系客户或操作外部账号。
```

## 完成标准与复盘

- 四类材料覆盖完整，三个交付文件实际可读，关键结论能回到来源。
- 至少识别一项冲突，缺失条件没有被编造成事实。
- 至少三项本人核验有记录，初稿问题修正后回读。
- 能说出一条可复用规则。真实阻塞需写清已做到哪一步，不能写成任务完成。
- 复盘：最容易被 AI 混淆的是金额、时间还是状态？哪些判断必须留给人？
