## 2. 我的工作流：浏览器 → 清单 → 预检 → 得到大脑 → 核验

| 阶段 | 做法 | 本次状态 |
|---|---|---|
| **浏览器** | 用调试端口连接已登录的浏览器会话 → 从任一课程文章回到课程目录 → 只提取安全字段（`order_num`、`title`、`enid`、发布状态、发布时间），在浏览器侧裁剪后再返回，不把完整响应带出 | **已执行** |
| **清单** | 生成规范网址 `https://www.dedao.cn/course/article?id=<enid>`，按 `enid` 去重，排除未发布/推荐/评论/其他课程 → 存为 `course-articles.json` | **已执行**（224 条） |
| **预检** | `sync_getnote.py --dry-run`：校验网址确属课程正文、合并重复、用标题搜索 + 来源网址核对判重。**只读取，不写入任何笔记** | **未执行**（权限校验即中断） |
| **得到大脑** | 预检确认后才批量提交网址，由 Get笔记自行提取全文；并发上限 3，失败重试一次，写入断点状态文件支持续传 | **未执行** |
| **核验** | 不把"退出码 0"当成功；以脚本最终状态为准，核对任务状态、笔记 ID、来源网址与已生成内容，必要时按标题反查落库结果 | **未执行**（无同步动作可核验） |

已执行的抽查：首篇 / 中段 / 末篇三处标题与清单完全一致，确认登录态有效且能打开正确正文。

## 7. 我遇到的真实阻塞及处理方式

| 阻塞 | 处理 |
|---|---|
| 浏览器调试端口连不上，WebSocket 握手 403 | 启动时补 `--remote-allow-origins=*` |
| 加了调试参数仍不生效 | 浏览器单实例会吞掉新参数 → 先彻底结束全部进程，再带参数启动 |
| 浏览器自动化工具连接频繁超时 | 改为用 Python 直连 CDP 执行与取数，稳定可控 |
| 目录分页取不全（一次最多 50 条，取多了返回空） | 摸清游标语义：`max_order_num` 是**下界**，`since_order_num` 是**上界**；构造干净请求体按游标翻页，取全 224 条 |
| 脚本在 Windows 上调用 `getnote` 报"找不到文件" | CLI 是 `.cmd`，无法直接被创建进程执行 → 修复为 Windows 走 shell 并做参数转义（其他平台逻辑不变）|
| **Get笔记 OpenAPI 仅对会员开放（未解决）** | 停在执行前，不伪造结果；预检与同步均记为"未执行"，等待开通后一条命令续跑 |

## 8. 我理解的"Skill 串联"是

把**一个完整任务拆成各司其职的几段**，用"流程技能"串起"原子技能"和外部能力：

- **流程编排**（本次的同步 Skill）：负责顺序、去重、断点续传、失败重试与最终汇总，是"总指挥"
- **原子能力**（认证 / 保存 / 搜索 / 知识库 / 标签）：每个只做一件事，可被任意流程单独调用
- **外部能力**（浏览器控制）：只负责**发现**网址，不碰内容

串联的关键是**边界清晰**：浏览器只发现不取正文，流程只判定不复制内容，原子技能只写入不删改既有数据；每一段都能单独失败、单独重跑，状态文件保证中断后不重复劳动。
