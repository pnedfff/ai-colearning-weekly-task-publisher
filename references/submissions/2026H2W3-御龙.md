1. **周次判断依据**：按学员实际领取的作业链接和作业正文主题判断周次，还是按 PR 标题或文件名判断？→ 确认：以作业链接和实际主题为准，PR 标题和文件名仅作参考。
2. **路径不规范如何处理**：PR #42 提交在根目录而非 `references/submissions/`，是否计入？→ 确认：内容能确认是单份 W3 作业报告且主题匹配时，兼容计入，但需备注路径问题。
3. **主题不匹配如何处理**：PR #39 内容为会议纪要清洗，不完全匹配 W3 任务结构，是否计入？→ 确认：标注为待维护者确认，不自行决定是否计入。
4. **脱敏遗漏如何处理**：PR #42 含真实企业名称，评论区副本是否需要脱敏？→ 确认：评论区副本必须脱敏，原 PR 风险需提醒维护者，不声称原 PR 已修复。
5. **人工抽查未完成如何处理**：PR #41 自注提示抽查可能未完成，如何标注？→ 确认：在同步评论中备注，提醒维护者确认，不代替学员声明完成。

## 9. 我做的一次人工纠正是什么

在处理 PR #42 时，最初考虑直接在评论区中引用 PR 的原始文件名作为示例。人工检查后发现该文件名包含真实企业名称，属于脱敏遗漏。纠正方式：将评论区副本中的文件名替换为泛化描述（"某工业产品企业的型号和数量清单"），同时在维护者备注中标注"原 PR 含真实企业名称，建议提醒学员后续脱敏"。不在评论区中暴露原始企业名称，也不声称原 PR 已修复。

## 10. 这次我学到的一条数据核查经验

> 异常值只是核查线索，不是自动修改指令。先确认标准再检查，比凭直觉发现问题更靠谱。

PR #39 标题和文件名都标为 W3，但实际内容是会议纪要清洗——如果只看标题就归入 W3，就会把不匹配的作业计入。先确认作业的实际主题和结构是否匹配 W3 标准，再决定是否计入，避免了误归类。
