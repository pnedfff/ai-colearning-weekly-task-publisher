## 对「Skill 串联」的理解

本次任务本质上是将两个已安装 Skill（dedao-course-to-getnote + ai-colearning-weekly-task-publisher）串联执行：

- **dedao-course-to-getnote** 处理"输入：得到课程 → 输出：Get笔记笔记"的全链路（抓包 → 解析 → 去重 → 同步）
- **ai-colearning-weekly-task-publisher** 处理"输出：打卡报告 → 发布：GitHub PR"的全链路（写入 → 提交 → PR）
- **串联关键**：两个 Skill 均依赖"规范输出格式 + 断点状态文件"，中间环节可独立验证、可替换、不污染

Skill 串联的价值在于：**每个 Skill 独立可信、接口清晰，可以像搭积木一样组合成完整工作流**。

## 可复用规则

1. **浏览器引擎直连**：避免 PowerShell 对参数解析问题，用 Node 脚本封装 engine eval
2. **DOM 诊断先行**：querySelectorAll 诊断后再填值，避免元素 ID/选择器不符导致 null 报错
3. **GitHub PAT 直接操作**：无需 CLI，REST API 可完成 fork/commit/PR 全流程
4. **分页游标统一**：getnote v1.5.7 用 --cursor 而非 --since-id，以 JSON 顶层 next_cursor 为准
