## 三、冲突之间的关联（人工确认时需注意）

```
C5（账号 +1）
   └─ 计费归属未定 ──→ 影响 C2（最终金额）
                          └─ C2 口径（含税/不含税）未定 ──→ 影响对外报价

C1（签约状态）
   └─ 若实为"未签署" ──→ 则 C4 付款期限的起算点（签署后）尚未触发
                       └─ 则 C3 试用日期不受合同约束，仅为客户期望

C3（试用日期）
   └─ 依赖技术排期（尚未出结果）──→ 与 C1 无关，但影响客户沟通口径
```

**提示**：C1 与 C5 是「牵一发动全身」的两项——签约状态决定付款与生效时点，账号计费决定最终金额。建议人工优先确认这两项。

## 四、本文件的判定纪律

1. 五项冲突**全部保留原值**，未以「时间更新」「数值更具体」等理由自动选定胜者。
2. 推算值（2000 元差额、6 个账号、10 个工作日≈14 自然日）均显式标注为推算，不伪装成原文事实。
3. 信息缺失一律归入「待确认」或写「原文未说明」，不以行业惯例填充。
4. 所有「待人工确认」为真实待办，不含任何 AI 侧隐含裁定。
