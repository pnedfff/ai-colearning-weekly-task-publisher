## 三、遇到的真实阻塞及处理方式

### 阻塞 1 · 课程正文提取为空（主阻塞）

16 篇全部失败，统一报错：

```
saved note has no extracted article content
```

即：笔记被创建了，但正文抓不到，落库为空壳。

**定位过程（三步排除法）：**

| 排查项 | 结论 |
| --- | --- |
| 账号额度 | 充足，`write_note` 34/1000，排除额度限制 |
| 权限 / 授权 | `Authenticated`，排除鉴权失败 |
| 抓取管线本身 | 用确定可访问的公开页做阳性对照，**抓到了完整标题 + 正文 + 标签**，管线正常 |

**初版定性**：付费 / 登录墙导致的权限受限——得到课程正文需要登录态 + 已购权限才能读到，而得到大脑是服务端抓取，拿不到浏览器里的得到登录 Cookie。

**处理方式**：按协议第 6 条——遇到权限受限**立即停止，不重复提交、不绕过**。我没有再跑第二轮批量，也没有尝试任何绕过付费墙的办法。

### 补录 · 免费课对照实验（2026-09-15，修正根因定性）

**动机**：初版把失败归因于「付费墙」，但这只是推断。若该定性成立，一门**完全免费**的课就应当能导入成功——这个推断可以直接用实验检验。

**实验设计（三组对照，变量隔离）**：

| 组别 | 样本 | 若「付费墙」定性成立 | 实际结果 |
| --- | --- | --- | --- |
| 对照组 | 公开静态页 | 成功 | ✅ 成功（标题 + 正文 + 标签齐全） |
| 付费组 | 本人已购付费课 16 篇 | 成功（已购 + 已登录） | ❌ 16/16 失败（空壳） |
| 免费组 | 得到站内一门 **0 元**课程（页面明示全部讲次可免费试读，非已购 4 门之列） | 成功（无付费墙） | ❌ **失败** |

**实验过程**（走题面协议的浏览器路线——「只粘贴链接，由得到大脑自行提取」，不复制正文）：

1. 在得到站内确认目标免费课：购买价 0 元，页面明示全部讲次可免费试读；
2. 打开得到大脑网页端 →「添加链接（AI 智能分析）」→ 粘贴课程链接 → 生成笔记；
3. 结果：页面提示**「笔记生成失败，请重试」**，最终落库为空壳笔记（标题"无标题"、正文仅链接本身）——与付费课失败后的空壳形态完全一致；
4. 失败样本**当场删除**（右键 → 删除 → 确认），笔记计数恢复原值，未污染笔记库。

**修正后的定性**：

> 「付费墙」不是根因，只是叠加在上面的另一层限制。**真正的阻断是：得到大脑的服务端抓取器无法读取得到课程页的正文**——得到课程页为重前端渲染并带访问限制，无论课程免费还是付费，服务端抓取都拿不到内容。付费组与免费组同型失败，而公开静态页对照组成功，三组对照即可锁定变量在「目标站点」而非「付费状态」或「工具本身」。

**处理方式**：遵守协议第 6 条，记录后停止，不批量重试（批量重试只会持续产生空壳笔记）。

## 五、对「Skill 串联」的理解

这周最大的收获不是导进了多少篇，而是第一次把**四种能力拆开、各司其职**地串成一条链：

| 环节 | 负责什么 | 保存物 |
| --- | --- | --- |
| 浏览器 | 发现课程自身 + 已发布正文 URL | URL 清单 |
| 本地清单 | 按 ID / URL 去重、预检 | 清单 + 状态文件 |
| 得到大脑 | 提取全文 | 笔记 |

之前我会把这三件事混在一起做，结果就是：一旦某个环节失败，根本说不清是**发现漏了**、**去重错了**，还是**提取被拦了**。

这次 16 篇全军覆没，但正因为链路是拆开的，我才能在 20 分钟内把问题精确定位到「提取环节被拦」——而不是笼统地归咎于「工具不好用」或「我操作有问题」。**链路拆得越清晰，失败越有诊断价值。**

另一个体会：**「跑通流程」和「任务成功」是两件事**。本周流程确实跑通了（5 步全部执行、每步都有可核验的产出物），但任务目标（课程正文进库）没达成。按题面要求以最终同步状态判定，我如实记为**未达成**，不拿「命令都跑完了」当完成。

## 六、下次可复用的一条规则

> **批量动作之前，先用一个「确定能成功」的最小样本做阳性对照，再决定要不要全量跑；下结论前，再用一组「否定该结论就会表现不同」的样本做反向验证。**

这条规则本周救了我三次：

1. **导入前先试 1 篇**——如果没试就直接全量跑 4 门课 39 篇，只会得到 39 条空壳笔记和一堆无法定位的噪音，清理成本翻倍。
2. **失败后先用公开页做对照**——如果没有这一步，我大概率会把「提取被拦」误判成「工具坏了」，然后去折腾工具、重复提交，既浪费额度又污染笔记库。
3. **补录用免费课做反向验证**——如果没有这一步，「付费墙」这个错误定性就一直挂在报告里。免费课同样失败，才把根因真正钉死在「得到大脑抓不到得到课程页正文」上。

**规则要点**：对照样本必须选**结果确定已知**的（我第一次拿了个 404 页面做对照，结论无效，白跑一趟）。对照成立 → 问题在目标侧；对照失败 → 问题在工具侧。一次对照胜过十次盲重试；而**反向验证**（选一个「如果结论错了它就会成功」的样本）能把「看起来合理的推断」变成「经过检验的结论」。
