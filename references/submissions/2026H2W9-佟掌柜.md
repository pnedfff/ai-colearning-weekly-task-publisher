## 8. 我理解的"Skill 串联"是

- **每个 Skill 是带边界的一步**：上一个 Skill 给出"可检查的中间产物"
  （如 `course-articles.json`、`<manifest>.sync-state.json`、同步汇总
  JSON），下一个 Skill 只信任这个中间产物，不重新发明轮子。
- **边界清晰，三件事分开做**：
  1. 浏览器只负责发现本人有权访问的 URL（不下载正文）。
  2. 本地清单只做规范化和去重（不写远程服务）。
  3. getnote 只接收 URL、自行抓取、自行落库（不重复保存）。
- **完成判定来自状态，不是退出码**：同步阶段必须看 sync-state.json 的
  每个 article 状态、`saved / duplicate-url / duplicate-title / failed`
  都要进入汇总；命令退出 0 不等于"全部成功"。
- **脱敏不是事后过滤，是设计原则**：本地清单、状态文件、登录态只留在
  本机；公共作业 PR 只描述流程与数字，从源头避免敏感信息外泄。
