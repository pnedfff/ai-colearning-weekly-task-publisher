## 6. 可复用步骤与需要调整

**可复用**：书架选书 → 右侧钢笔图标 → 先读面板「共 N 条」确认总量 → 面板内小步滚动逐屏读 → 按章节标题归位 → 读完用 N 对账，少一条就补读，不靠印象说「已读完」。

**需要调整**：
1. 无笔记的书不显示「复制全部笔记」，也没有筛选控件，范围只能靠换书或换章节。
2. 面板是自定义渲染，DOM 读不到笔记文本，只能截图逐屏读；滚动幅度过大会漏条或把面板收起，需小步滚动。
3. 遇到选中文字弹出的划线工具栏要避开，否则会变成写入账号内容。
4. 面板不显示笔记时间、不显示本人自写想法 → 这两项必须如实写「未取得」，不能拿原书摘录冒充。
5. 图标规则可复用：三角「A」= 原书划线，圆形人像 = 本人想法（在两本书上互证，其中一本有「个人想法：」显式文字标识）。仍以本人确认为准。
