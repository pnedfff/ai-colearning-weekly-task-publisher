## 二、W9 失败根因（判别实验）

- 对照实验：同一环境分别提交「公开普通网址」与「得到文章 URL」走服务端抓取保存。公开网址成功，得到文章 1 秒内返回失败。
- 结论：得到正文受登录墙保护，服务端抓取拿不到内容，失败与账号权限无关。W9 报告中「平台级限制」的推断由此升级为可复现的实验结论。
- 推论：W9 采用的网页路线（让得到大脑服务端抓链接）在此类文章上不可行，必须换通道。

## 三、管线重构（可复用路线）

1. 发现/提取：CDP 自动化浏览器 + 本人登录态，在课程/文章页提取正文文本（仅本机处理）。
2. 入库：得到大脑 OpenAPI（平台开发者身份 + API Key），`note/save` 以纯文本直存，不走服务端抓取。
3. 查重/核验：`note/list` 全量分页扫描。实测该接口为游标分页（page 参数无效，需链式翻页），扫描全库后按标题逐一核对。

避坑记录：部分站点的页面内 fetch 调试会令自动化进程静默崩溃，改用导航直读接口响应；分页参数以实测为准，不按文档想当然。
