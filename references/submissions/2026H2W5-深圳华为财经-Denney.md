## 1. 我这周练的任务

我教 Codex 完成一个低风险 Windows 界面操作：在系统记事本中打开一份本地脱敏草稿，写入固定的验证内容并保存。

本周主仓库尚未发布 `2026H2W5` 的详细任务文件，因此我按主分支半年度规划完成：流程评估、单条回放、可复用 SOP 和风险清单。

## 2. 流程评估

| 评估项 | 结论 |
| --- | --- |
| 操作对象 | 本地脱敏文本草稿 |
| 外部影响 | 无网络上传、无消息发送、无账号操作 |
| 可逆性 | 高；仅修改练习草稿，可重新生成 |
| 主要风险 | 激活错窗口、覆盖已有内容、保存到错误文件 |
| 自动化判断 | 适合单文件、固定文本、明确目标窗口的受控回放 |

我将删除文件、批量覆盖、对外发送、登录和权限变更排除在本次自动化之外。

## 3. 我让 AI 做了哪些步骤

1. 读取主仓库日历，确认当前为 `2026H2W5`。
2. 检查主分支，确认详细周任务文件尚未发布，并读取半年度规划中的目标与产出。
3. 选择低风险流程，准备一份不含真实业务数据的本地草稿。
4. 启动独立系统记事本窗口，并按窗口标题和进程标识激活目标窗口。
5. 全选草稿占位内容，输入固定的脱敏验证文本。
6. 保存后重新读取文件，核对四行内容是否完整写入。
7. 整理 SOP、风险清单和人工判断点。

## 4. 单条回放记录

- 回放对象：`回放产物_脱敏周报草稿.txt`
- 回放结果：成功
- 写入内容：任务标识、成功状态、本地范围和风险边界，共四行
- 保存验证：文件重新读取后四行内容与预期一致
- 异常与处理：首选 Windows 自动化接口无法取得 Notepad++ 前台进程句柄；第一次原生窗口回放虽然返回“已激活”，但磁盘读回仍是占位文本，被验收拦截。随后改用“窗口标题 + 实际进程”重新定位系统记事本，第二次回放成功写入四行内容。最终按行读回一致；仅换行符格式存在 Windows 与 PowerShell 表示差异，不影响文本内容。

## 5. 可复用 SOP

1. 只选择低风险、可逆、无外部发送的操作。
2. 新建专用练习文件，禁止直接使用真实业务文件。
3. 启动独立应用窗口，记录目标进程或窗口标识。
4. 输入前再次核对窗口标题和目标文件名。
5. 每次只回放一个文件、一个动作链。
6. 保存后必须重新读取结果；内容不一致就停止，不连续重试。
7. 涉及删除、覆盖重要文件、发送、登录或权限变化时，必须转人工确认。

## 6. 风险清单

- 激活错窗口：使用独立窗口和进程标识，输入前核对标题。
- 覆盖原内容：只操作专用练习副本，不碰真实业务文件。
- 保存路径错误：固定目标文件名，保存后从磁盘重新读取。
- 自动化失控：限制为单次回放，不使用循环和批处理。
- 敏感信息泄露：只写脱敏示例，不粘贴客户、账号、密钥或内部数据。

## 7. 哪一步最有用

最有用的是“保存后重新读取”。界面看起来执行成功不等于文件真的保存正确，读回结果才是完成证据。

## 8. 哪一步需要人来判断

人需要判断任务是否真的低风险，以及目标文件是否允许覆盖。只要涉及重要文件、外部发送、账号登录或权限改变，就不应直接自动执行。

## 9. 下次会复用的一句话提示词

> 先评估这个界面操作是否低风险、可逆且无外部影响；只用脱敏副本单次回放，操作前核对目标窗口，保存后重新读取验证，遇到删除、重要覆盖、发送、登录或权限变化立即停下让我确认。
